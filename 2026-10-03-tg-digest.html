告诉 AI 遇到什么情况该做什么、先做什么后做什么、什么时候应该追问、什么时候应该拆任务、怎么验证结果、怎么做 Review。

你给一个任务，它会先逼着把事情讲清楚：

需求是什么？边界在哪里？有哪些方案？具体怎么实现？

简直就是把成熟团队的SOP，迁移到AI上！

1. 关于定位

大家对于 personal agent 的很多定位是 "extension of yourself"。如果真的是你自身的延伸，那么它就不应该有独立的人格（personality），不应该有头像，更不应该是一个独立的个体。

  1. 关于入口与 Computer Use

这一波很多人通过 computer use 调用第三方的非开放软件，来实现原本实现不了的功能。但如果你可以 computer use 别人，别人为什么不可以 computer use 你？那最终的入口到底会在哪里？

身上的一个位置往往只能佩戴一件硬件，而硬件是不会轻易被这样取代的，所以硬件可能会是最 persistent、最坚固的入口。

  1. 关于运行环境

大家总希望 agent 能够 continuously running on the cloud，这个点我特别 buy in。但为什么它不能 continuously running in the real world，在你身边围绕着你？我觉得这是一个被大家忽略的奇怪盲点。

  1. 关于随时随地的交互

大家总希望 anytime, anywhere 都可以 talk with agent，目前陆陆续续在 iMessage、WhatsApp、Slack、邮件等渠道都能实现对。但就像看 Dots 那个发布片一样，无论在什么地方都得对着一台亮着屏幕的手机，这其实是一种很奇怪的交互。我认为真正的 anytime, anywhere，最应该增加的是线下的入口、线下的 context 以及线下的交互
